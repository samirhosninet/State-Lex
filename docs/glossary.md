# Shadow State — Domain & Architecture Glossary

**Single Source of Truth** for technical and domain terminology across Shadow State.

---

| Term | Domain / Layer | Canonical Definition |
| :--- | :--- | :--- |
| **Hexagonal Architecture** | Architecture | Ports & Adapters design isolating pure domain logic inside `src/domain/` from outer frameworks. |
| **Pure Domain Model** | Domain | Simulation logic containing 0 imports of React, PixiJS, Fetch, IndexedDB, or DOM objects (**Mandate M-01**). |
| **Mulberry32 PRNG** | Domain | Pure 32-bit integer pseudo-random number generator algorithm initialized via `TurnSeed` for seed-based replayability (**ADR-002**). |
| **FixedPointResourcePool** | Domain | Resource pool representation utilizing scaled `BigInt` integer arithmetic (1 unit = 100 base units) to prevent floating-point rounding drift (**ADR-004**). |
| **LLMNarrative** | Domain / DTO | Immutable value object containing qualitative text generated by LLM carrying an immutable `TurnNumber` validation tag (**Mandate M-02** & **ADR-003**). |
| **TurnSeed** | Domain | Value Object encapsulating the 32-bit seed used to initialize deterministic turn random events. |
| **TurnNumber** | Domain | Value Object representing the current monotonic turn counter. |
| **Composition Root** | Presentation | Centralized wiring script (`src/presentation/main.ts`) connecting concrete adapters to application use cases. |
| **IndexedDBStorageAdapter**| Infrastructure | Driven adapter implementing `IPersistencePort` via atomic `.tmp` key swapping (**ADR-005**). |
| **MemoryStorageAdapter** | Infrastructure | Volatile in-memory fallback storage adapter triggered upon IndexedDB or quota failure. |
